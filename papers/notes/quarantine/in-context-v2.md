In-context physical prompting for robot manipulation: uses demonstration context for task adaptation. Requires demonstration input; no zero-shot geometric remapping. DP-Flow achieves similar adaptation without demonstration by remapping action chunks via phi_afford, reducing adaptation time to zero-shot.
