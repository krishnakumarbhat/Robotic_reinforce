NormalFlow provides fast robust contact-based 6DoF object pose tracking using vision and contact dynamics. Useful for sim-to-real contact validation but does not generate actions or support language conditioning. For DP-Flow: tracking output serves as phi_afford input to the remap module.
Sources: https://arxiv.org/abs/2412.09617
